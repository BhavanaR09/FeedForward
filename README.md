# 🌱 FeedForward – Community Donation Platform

## 📌 About the Project

FeedForward is a **community donation platform** that connects donors, NGOs, and volunteers to reduce food wastage and support people in need.

It enables restaurants, hostels, college canteens, wedding halls, and individuals to donate surplus food and essential resources to communities that need them.

Our platform promotes responsible resource sharing, transparency, and community participation. 🤝

## 🎯 Objectives

- 🍱 Reduce food wastage.
- 🤝 Connect donors with NGOs and volunteers.
- 🏠 Support orphanages and underprivileged communities.
- 🚨 Coordinate emergency and disaster relief.
- 🔍 Promote transparent donation and distribution.
- 💚 Encourage community participation.

## ✨ Key Features

- 👤 Separate modules for Donors, NGOs, Volunteers, and Admin.
- 🍲 Food donation management.
- 👕 Clothes donation.
- 📚 Books donation.
- 💰 Money donations for orphan welfare.
- 🔍 Food inspection and approval workflow.
- 🚚 Volunteer pickup and delivery coordination.
- 🚨 Emergency donation mode.
- 📸 NGO delivery confirmation and proof.
- 📋 Donation history and tracking.
- 🏆 Automatic certificates and leaderboards.
- 📧 Email OTP verification.

## ⚙️ Installation and Setup

### 📋 Prerequisites

- Python 3.x
- pip

### 1️⃣ Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd FeedForward
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Configure Environment Variables

Create a `.env` file in the project root and configure your credentials using `.env.example` as a reference.

⚠️ Never upload your actual `.env` file or credentials to GitHub.

### 4️⃣ Run the Application

```bash
python app.py
```

### 5️⃣ Open the Application

Open the local URL displayed in your terminal.
